# Fullstack · Un checkout simulé et idempotent — élève

**4 h 30 · Java / React / Paiement simulé · PilotCrew.** Relier Java et React à un simulateur local, puis prouver qu’un rejeu ne crée pas une nouvelle tentative.

Un paiement de ce cours est une tentative fictive. HTTP 202 produit un état PENDING ; le résultat terminal arrivera dans le lab 04.

Ce support contient les tutoriels, mémos et espaces de réponse. Créer le code demandé dans `backend/` et `frontend/` ; le corrigé est privé et séparé. Les six séances forment un fil rouge progressif de **27 heures**, sans promesse de niveau senior.

## Préparer la séance

Avant cette séance, importer votre réalisation validée de `java-react-02-react-eleve` dans votre nouvelle copie `java-react-03-checkout-eleve`. Reprendre backend/, frontend/ et scripts/ lorsqu’ils existent, ainsi que leurs configurations et lockfiles. Exclure .git/, target/, node_modules/, dist/, caches et sorties privées. Garder les documents de ce nouvel atelier. Noter le commit de provenance et exécuter les contrôles disponibles avant le début des 270 minutes.
